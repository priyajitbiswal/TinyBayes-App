# TinyBayes

TinyBayes is an Android app for cocoa leaf disease detection. It runs fully on-device with TensorFlow Lite and classifies an image as one of three labels:

- Healthy
- CSSVD
- Anthracnose

The app lets you either take a photo or choose one from the gallery, then preprocesses the image, runs it through a MobileNetV3 Small model, and applies Jacobi coefficient scores to produce the final diagnosis.

## Features

- Camera capture and gallery image selection
- On-device inference with no network dependency
- Simple Compose UI with the selected image preview and prediction result
- Release build configured for shrinking and minification

## Tech Stack

- Kotlin
- Jetpack Compose Material 3
- TensorFlow Lite
- Gson
- Android Gradle Kotlin DSL

## How It Works

1. The user captures a photo or picks an image.
2. The image is resized to 224 x 224 and normalized.
3. `mobilenet_v3_small.tflite` produces a 576-dimensional feature vector.
4. `jacobi_coefficients.json` provides class weights for Healthy, CSSVD, and Anthracnose.
5. The highest score becomes the prediction shown in the UI.

## Project Structure

- `app/src/main/java/com/example/tinybayes/MainActivity.kt` - Compose UI and image picking/capture flow
- `app/src/main/java/com/example/tinybayes/DiseaseClassifier.kt` - TFLite inference and class scoring
- `app/src/main/java/com/example/tinybayes/FileUtil.kt` - Asset loading helper
- `app/src/main/java/com/example/tinybayes/JacobiCoefficients.kt` - JSON model for the class coefficients
- `app/src/main/assets/` - Model and coefficient data used at runtime

## Requirements

- Android Studio or another IDE with Android support
- JDK 11
- Android SDK 36 or compatible SDK tooling

## Build and Run

From the project root:

```bash
./gradlew assembleDebug
```

To install on a connected device or emulator:

```bash
./gradlew installDebug
```

You can also open the project in Android Studio and run the `app` configuration.

## Testing

The project includes the default unit and instrumentation test stubs generated by Android Studio. Run them with:

```bash
./gradlew test
./gradlew connectedAndroidTest
```

## Notes

- The app processes images locally on the device.
- The model and coefficient files are stored in `app/src/main/assets/`.
- Release artifacts and other generated outputs should stay out of version control.
